# Культура Стиля — демонстрационный сайт

Выбранный вариант: **Студия крупным планом**. GitHub Pages открывает только эту
страницу; каталога других концептов здесь нет. Это экспорт готовой статической
сборки. Канонический проект ведётся отдельно; правки нужно переносить через него.

Это неофициальный демо-концепт, подготовленный PMXP как предложение салону.
Реальные услуги, цены, публичные фотографии и сотрудники сохранены в сборке.
Публичный виджет YCLIENTS используется только для просмотра доступности.
Выбор времени не создаёт запись; подтверждение, контактный ввод в виджете,
оплата и изменение данных отключены. Расписание зависит от внешнего сервиса.

Имя, телефон, пожелания и локально добавленные фотографии остаются только в
оперативной памяти вкладки. Они не отправляются серверу и исчезают при закрытии
вкладки либо явном сбросе заявки. Постоянно сохраняется только цветовая тема.

## Публикация

В настройках GitHub Pages выберите корень публикуемой ветки. Файл `.nojekyll`
сохраняет статические пути. Корневой `index.html` ведёт в `cinema-studio/`.
Не переносите исследовательские материалы, QA, серверные секреты или другие
концепты в этот репозиторий. `_export-manifest.json` перечисляет файлы экспорта.

У сторонней телефонной библиотеки сохранена исходная MIT-лицензия в
`shared/vendor/libphonenumber-LICENSE.txt`. Фотографии используются в рамках
неофициального предложения; это не разрешение на их дальнейшее использование.
